# 粗测工具说明

这个目录用于存放**轻量级功能测试工具与说明文档**，目标不是做特别细的自动化测试，而是快速确认项目核心功能没有明显坏掉。

---

## 文件说明

- `运行粗测.ps1`
  - 一键执行粗测的 PowerShell 脚本
- `smoke_admin_health_records.py`
  - 管理员健康记录摘要接口的独立冒烟测试

---

## 运行方式

在项目根目录执行：

```powershell
.\测试\运行粗测.ps1
```

---

## 这个脚本测试了什么

脚本当前会依次执行下面 4 类检查：

### 1. 后端关键模块语法检查

检查这些核心文件是否存在明显语法错误：

- `backend/app/features/health_data/router.py`
- `backend/app/features/admin/router.py`
- `backend/app/features/admin/service.py`
- `backend/app/schemas.py`

用途：

- 防止后端核心功能因为语法错误无法启动

---

### 2. 后端 P0 粗测

调用现有的一部分 P0 测试，覆盖核心主流程：

- 用户注册 / 登录
- 管理员登录
- AI / RAG 主要流程
- 文档导入
- 健康资料公开访问
- PDF 健康记录上传

这里刻意选的是**当前适合做粗测、能稳定跑通的用例**，不是全量严格测试。

---

### 3. 管理员健康记录摘要接口粗测

独立检查新增的管理员接口：

- 用户创建一条健康记录
- 管理员登录
- 请求 `/api/admin/system/health-records`
- 验证：
  - 能返回记录摘要
  - 能看到用户名
  - **不会返回具体正文**
  - **不会返回附件内容**

用途：

- 确认管理员端“只看摘要、不看内容”的功能没有被破坏

---

### 4. 前端构建检查

执行：

```powershell
npm run build
```

用途：

- 确认 Vue 页面、路由、API 改动没有导致前端打包失败

---

## 粗测的定位

这个脚本的定位是：

- **快速检查**
- **日常改完后跑一遍**
- **确认核心功能没明显坏**

它不等于完整测试，也不覆盖：

- 复杂边界条件
- 性能
- 安全
- 全量 UI 行为
- 全量链上异常场景

---

## 推荐使用场景

建议你在这些时机运行：

1. 改完后端接口后
2. 改完用户端健康数据页后
3. 改完管理员功能后
4. 准备提交到 GitHub 前
5. 准备演示或发版前

---

## 运行前提

请确保：

1. 已创建虚拟环境：

```powershell
python -m venv .venv
```

2. 已安装后端依赖：

```powershell
.\.venv\Scripts\pip.exe install -r backend\requirements.txt
.\.venv\Scripts\pip.exe install httpx
```

3. 前端依赖已安装：

```powershell
cd frontend
npm install
```

---

## 一句话总结

这个目录里的脚本，主要帮你做：

> **后端核心接口粗测 + 管理员摘要接口检查 + 前端构建检查**

适合作为你项目的**日常一键冒烟测试工具**。
